## Week 1 - History
- One writing system can be used by many languages
- Cuneiform looks weird
- The Epic of Gilgamesh was epic
## Week 2 - Bits and Bytes
...
- RAM is short-term (volatile) memory; storage is persistent. RAM is wiped when power is off
- Computers store numbers and characters as bits; the ASCII table maps numbers to characters
- Text files vs binary files: text files are made of readable characters, binary files are not meant to be read in an editor
- A GitHub repo address looks like github.com/username/repository_name
## Week 3 - Text Structure and Markup
- Markup languages (Markdown, HTML) have a raw view and a rendered view
- Structured data formats: JSON and XML
- Special characters sometimes need "escaping" with a backslash, e.g. `\*` to show an asterisk
- Markdown link syntax: `[name](url)` with no space between `]` and `(`
- Wrap ASCII art in a code block (triple backticks) to keep the alignment

## Week 4 - Editors, Shortcuts and Search
- Common shortcuts: Ctrl-C copy, Ctrl-V paste, Ctrl-Z undo, Ctrl-A select all, Ctrl-F find
- Replace `.com` with `.dev` in a GitHub repo URL to open the github.dev editor
- Regex basics: `\d` is a digit, `+` is one or more, `*` is zero or more, `^` is start of line, `$` is end of line
- A commit needs a message; commits trigger the autograder under the Actions tab

## Week 5 - Command Line
- Connect with SSH: `ssh bandit0@bandit.labs.overthewire.org -p 2220`
- Passwords typed in the terminal are not displayed, not even as `*`
- Key commands: `ls` (`-a` hidden files, `-l` long form), `cd` (`cd ..` goes up), `cat` and `less` (quit with `q`), `man` for help
- Spaces in file names need quoting (`"my file.txt"`) or escaping (`my\ file.txt`)
